ขั้นตอนการนำไฟล์ HTML นี้ไปสร้าง GitHub Pages (อัปโหลดเว็บใช้งานฟรี)

  1. บันทึกไฟล์: บันทึกซอร์สโค้ดนี้ทั้งหมดไว้ในเครื่องคอมพิวเตอร์ของคุณ ตั้งชื่อไฟล์ว่า index.html
  2. สร้าง Repository ใน GitHub: เข้าไปที่เว็บไซต์ GitHub.com ล็อกอินเข้าใช้งาน กดปุ่ม New Repository ตั้งชื่อเช่น covid-thailand-dashboard และเลือกสถานะเป็น Public
  3. อัปโหลดไฟล์: ในหน้า Repository ที่สร้างขึ้น คลิกที่ปุ่ม "uploading an existing file" ลากไฟล์ index.html วาง แล้วกด Commit changes
  4. เปิดการใช้งาน GitHub Pages:
    • ไปที่แถบเมนู Settings ด้านบนของ Repository
    • เลือกเมนูด้านซ้าย Pages
    • ตรงส่วน Build and deployment > Branch เปลี่ยนจาก None ให้เป็น main แล้วกด Save
  5. เข้าชมเว็บ: รอระบบสร้างหน้าเว็บประมาณ 1-2 นาที คุณจะได้ URL เช่น https://username.github.io/covid-thailand-dashboard/ สามารถเปิดดูและส่งต่อได้ทันที
